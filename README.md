# 🎮 XOverse - Tic Tac Toe Game

XOverse is a simple and interactive Tic Tac Toe game developed using Python and Pygame. The game provides a clean and enjoyable experience where two players can compete against each other on a 3×3 game board.

## ✨ Features

- 🎯 Classic 3×3 Tic Tac Toe gameplay
- 👥 Two-player mode
- ❌ Player X and ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart and play again
- 🖥️ Simple and user-friendly interface
- ⚡ Fast and lightweight

## 🛠️ Technologies Used

- Python
- Pygame

```bash

```

```bash
python main.py
```

## 🎮 How to Play

1. Start the game.
2. Player X makes the first move.
3. Players take turns selecting an empty cell.
4. The first player to get three symbols in a row wins.
5. The game detects a draw if all cells are filled without a winner.
6. Restart the game and play again.

## 🏆 Winning Conditions

A player wins by placing three identical symbols:

* ➡️ Horizontally
* ⬇️ Vertically
* ↘️ Diagonally
